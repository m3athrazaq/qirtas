# قِرطاس — Qirtas

**الويب:** https://qirtas-al8.pages.dev · **الأندرويد:** ملف APK في صفحة [Releases](../../releases/latest)

دفتر ملاحظات ومهام عربي أولاً: صفحات بمحرر كتل، قواعد بيانات بعروض جدول ولوحة وتقويم هجري،
بحث يفهم العربية، مساعد كتابة، مشاركة وتعاون مباشر، ويعمل دون اتصال على الويب والأندرويد.

## المزايا

- **محرر كتل**: قائمة `/`، اختصارات Markdown (`#` `-` `[]` `>`)، صفحات متداخلة، سحب الكتل، ألوان وتمييز وروابط وكود، أيقونات وأغلفة، تصدير Markdown وPDF.
- **تراجع وإعادة بلا حد**: للكتابة ولعمليات الصفحات وقواعد البيانات، وسجل كل صفحة يبقى طوال الجلسة (`src/data/history.ts`).
- **جداول سهلة**: مقبض لكل صف وعمود (إدراج، تكرار، مسح، حذف) وزر + لإضافة صف أو عمود (`src/editor/TableControls.tsx`).
- **اتجاه تلقائي لكل سطر**: العربي يمين والإنجليزي يسار في الصفحة نفسها.
- **قواعد بيانات**: جدول ولوحة (Kanban) وتقويم؛ خصائص الحالة والأولوية والتاريخ والمسؤول والرقم والرابط؛ تصفية وترتيب؛ فتح أي صف كصفحة؛ تحويل قائمة إلى قاعدة بيانات.
- **التقويم الهجري (أم القرى)**: الأسبوع يبدأ الأحد، وتاريخان معاً هجري وميلادي.
- **مهام متكررة**: يوميًا أو أيام العمل أو أسبوعيًا أو شهريًا أو سنويًا، بالهجري أو الميلادي؛ إنجاز المهمة ينقل تاريخها وتذكيرها إلى الموعد التالي، مع نسبة إنجاز اليوم (`src/data/recurring.ts`).
- **آيات القرآن**: `/آية` ثم مرجع («البقرة ٢٥٥»، «2:255-257») أو اسم سورة أو كلمات من الآية بإملاء عادي؛ تُدرج بالرسم العثماني وخط أميري قرآن مع المرجع (`src/quran/`).
- **استيراد من تطبيقات أخرى**: Notion (Markdown & CSV، مع الجداول وصفحات الصفوف)، وخزنة Obsidian (روابط `[[…]]` والصور)، وGoogle Keep (Takeout)، وEvernote (‎.enex)، وملفات Markdown ونصوص وHTML وCSV (`src/import/`).
- **بحث عربي**: يتجاهل الهمزات والتشكيل والتاء المربوطة والألف المقصورة والأرقام الهندية، مع إبراز النتائج (`Ctrl/⌘ K`).
- **مساعد الكتابة**: تلخيص، إكمال، تدقيق إملائي ونحوي، تحويل اللهجة إلى فصحى، ترجمة، اختصار، وتحويل الملاحظة الصوتية إلى ملاحظة منظمة.
- **مشاركة**: روابط دعوة بصلاحية تعديل أو عرض، وتعديل مباشر مع رؤية من يتصفح الصفحة.
- **مزامنة ودون اتصال**: كل شيء يُحفظ على الجهاز أولاً ثم يُزامن (Yjs + خادم على Cloudflare لا يتوقف). تُربط الأجهزة برمز لمرة واحدة، ولا تنتهي الجلسة.
- **قوالب**: رمضان، ختمة القرآن، مشاريع، محاضرات، واجبات، محضر اجتماع، ميزانية شهرية، سفر، قراءة، عادات، يوميات، خطة أسبوعية.
- **واجهة عربية وإنجليزية**، ووضع داكن.

## البنية

| المجلد | المحتوى |
| --- | --- |
| `src/editor` | المحرر (TipTap) وكتله وقائمة `/` وشريط التنسيق |
| `src/database` | قواعد البيانات: الجدول واللوحة والتقويم والخصائص |
| `src/data` | التخزين المحلي (IndexedDB + Yjs) ومساحة العمل والتنقل |
| `src/sync` | ربط الأجهزة والمزامنة والمشاركة |
| `functions/api` | خادم المزامنة (Cloudflare Pages Functions + قاعدة D1) |
| `src/ai` | مساعد الكتابة والملاحظات الصوتية |
| `src/lib` | العربية والهجري والترجمة والتصدير |
| `supabase/` | الخادم القديم (لم يعد مستخدماً) |
| `android/` | تطبيق الأندرويد (Capacitor) |
| `e2e/` | اختبارات المزامنة (خادم محلي) والأندرويد (محاكي) |

## التطوير

```bash
npm install
npm run dev          # http://localhost:5173
npm run build:web    # نسخة الويب في dist/
npm run android      # بناء الويب ونسخه إلى مشروع الأندرويد
```

عنوان الويب العام في `.env.production` (يستعمله تطبيق الأندرويد للوصول إلى خادم المزامنة). أثناء التطوير المحلي يعمل التطبيق دون مزامنة؛ ولتجربتها محلياً:

```bash
npm run build && npx wrangler pages dev dist   # التطبيق مع الخادم وقاعدة بيانات محلية على 8788
```

## الإعداد لمرة واحدة

1. **قاعدة البيانات**: في Cloudflare ← Storage & databases ← D1 أنشئ قاعدة باسم `qirtas-sync`، وضع معرّفها في `wrangler.jsonc`. ينشئ الخادم جداوله بنفسه عند أول طلب. حدود الخطة المجانية يومياً: 100 ألف طلب، و5 ملايين صف مقروء، و100 ألف صف مكتوب؛ و500 ميغابايت للقاعدة.
2. **توقيع الأندرويد**: أضف السرّ `ANDROID_KEYSTORE_PASSWORD` في إعدادات المستودع. المفتاح نفسه في `android/signing/` ومقفل بكلمة المرور.
3. **الويب**: اربط المستودع بـ Cloudflare Pages؛ أمر البناء `npm run build:web` والمجلد `dist`. ربط قاعدة D1 يأتي من `wrangler.jsonc`، ورؤوس الحماية (CSP وغيرها) في `public/_headers`.
4. **المساعد (اختياري)**: في مشروع Pages ← Settings ← Variables and Secrets أضف السرّ `ANTHROPIC_API_KEY` (و`AI_MONTHLY_LIMIT` إن شئت؛ الافتراضي 300 طلب شهرياً لكل حساب).

## النشر

- كل دفع إلى `main` يبني ملف APK موقّعاً وينشره في صفحة **Releases** باسم `v1.1.<رقم>`.
- سير العمل **Sync test** يشغّل الخادم بقاعدة محلية ويختبر واجهته، ثم ربط الأجهزة والتعديل في الاتجاهين والعمل دون اتصال والإزالة ونقل جهاز إلى الحساب الصحيح، في متصفحات عدة.
